## 文档更新约定

1. 每次修改成员、组别、权限、任务、资金或发票行为时，同步更新对应 **使用手册 + 技术说明**，不只新增独立的变更记录。
2. 代码路由、环境变量或迁移发生变化时，同步更新 **配置参考 / 源码导读 / 运维手册**。
3. 用“源码已实现 / 已自动化验证 / 已人工验证 / 已部署”四种说法区分状态；不据 Git 提交推断线上服务已更新。
4. 不在公开文档里维护人员账户名单、真实私钥位置、内部固定地址或敏感业务样本；本仓库旧历史提交不能靠修改当前文档清除。
5. 合并前检查 Markdown 相对链接、CI 和文档涉及的命令；部署和恢复操作需人工执行并记录。
