## 数据与恢复契约

审计 `AUDIT_RETENTION_DAYS=0` 与 `AUDIT_MAX_ROWS=0` 同时关闭清理，关闭无法恢复已删除记录。保护记录可使行数超过上限。代码回滚不删除业务库或附件；恢复备份需要另行确认。

发票入库在写锁中先保存元数据再同文件系统原子移动；跨文件系统不退化为复制。补偿失败单独记录并提示核查；不承诺任意进程崩溃下多文件原子事务。权威文件/元数据已经成功时，非权威缓存失败不返回“未入库”。读快照失败标记由前端显示；当前用户权限和当前元数据归属始终重新校验。

systemd 仅修改模板并做语法检查，写路径覆盖默认根目录数据库/WAL/密钥及子目录业务文件。定制目录须在 staging 补全 ReadWritePaths；没有在线运行验收。APK 测试只做签名解析、隔离假构建器与 Java 编译，不生成 APK。
