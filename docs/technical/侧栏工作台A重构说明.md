# 侧栏工作台 A：第四轮 UI 架构实施说明

## 路由 / 导航
| 页面 | 地址 | 访问角色 | 说明 |
|---|---|---|---|
| 工作台 | `/` | 全员 | 任务数据驱动的实时概览、近期任务、常用操作；不显示虚构财务指标 |
| 任务中心 | `/tasks` | 全员 | 保留按成员/状态看板、任务详情和编辑权限 |
| 任务管理 | `/manage` | admin/manager | 创建、筛选、编辑、删除任务 |
| 成员管理 | `/members` | admin/manager | 独立成员列表、导入、角色、启停、重置密码 |
| 资金台账 | `/funds/` | admin/manager | 保留资金流程与 Bootstrap 子页签 |
| 发票中心/我的发票 | `/invoices/` | 全员（数据分权） | 保留单批上传、查重、报销管理 |
| 账户设置 | `/account` | 全员 | 个人资料、改密 |

## 组件化原则
- 三个业务模块使用相同的 `_workspace_sidebar.html` 与 `_workspace_top.html`，不复制侧边栏 DOM。只通过服务端角色控制菜单可见性，后端已有角色校验不变。
- `workspace.css` 是最后加载的布局层，旧业务 CSS 和业务 DOM/ID 保留，便于逐步清理。
- 宽屏 242px 固定深色导航，小于等于 850px 为带遮罩的抽屉导航，支持 Escape 和遮罩关闭。
- CSV 始终位于所属列表/业务页面标题区：任务中心/任务管理、成员管理、资金台账、发票中心；成员 CSV 是新增接口，不导出密码，转义可能被电子表格解释为公式的文本。
- 原有 `/export.csv`、`/funds/api/export`、`/invoices/api/export/download` 保留；发票管理员 CSV/ZIP 仍按原权限。
- 发票模板从读取原始 HTML + 字符串替换改为 Flask Jinja2 模板渲染，内嵌角色配置使用 `tojson`，不修改 PDF 业务处理。
- 保留 HTTP 部署方式，不规划 HTTPS；不修改既有 SQLite 表结构及发票数据。

## 手工验收建议
1. 桌面和手机登录、侧栏开合、返回工作台、退出、成员权限过滤。
2. 任务中心的状态/负责人视图和编辑弹窗；任务管理的创建与删除；成员管理的导入、密码重置、角色变更。
3. CSV 文件下载及 Excel 中文显示；尤其是新成员 CSV 不包含密码哈希。
4. 资金录入、复审、图表、过滤、导出，确认 Bootstrap 页签与编辑模态框正常。
5. 发票单/批上传、预览、查重、审批、统计、导出、移动端滚动；普通成员不能看到财务操作。
6. 无网络/CDN 可用时，资金模块 Bootstrap 的降级行为需后续单独改造。

此分支仅更换布局和轻量前端组织方式，未替换资金/发票存储和流程 API。
