# 异地电脑接管与并行控制

本文面向获授权的维护人员。连接地址、账户和网络拓扑请从**私有运维记录**获取；不要把真实私钥、服务器公网地址或业务数据库写入公开 PR。

## 新电脑加入维护

1. 在新电脑安装 OpenSSH 或 VS Code Remote-SSH。
2. **各人单独生成密钥对**（可选密码短语，推荐设置）：

       ssh-keygen -t ed25519 -f ~/.ssh/xtyf-maintainer

3. 仅把 `.pub` 公钥交给有管理权限的人，核对人员身份后加到服务器对应账户的 `~/.ssh/authorized_keys`。
4. 使用组织提供的实际内网主机地址验证登录：

       ssh -i ~/.ssh/xtyf-maintainer <user>@<host>

5. 使用 VS Code Remote-SSH 时在本机 SSH config 设置 HostName/User/IdentityFile，不要把私钥拷到仓库里。

不要共用管理员现有私钥，避免无法追溯操作和批量失窃风险。异地连接方式（可信 VPN、跳板等）由运维决定，不默认将 SSH 端口暴露公网。

## 多人协作约定

| 任务 | 推荐做法 |
| --- | --- |
| 读日志、查状态 | 可并行，只读 |
| 修改代码 | 以 Git 分支/PR 变更，避免直接编辑运行目录 |
| 部署/迁移/重启 | 指定单一值班者执行；先备份、测试并记录 commit |
| 改数据库/票据 | 不直接操作生产原始数据；使用经过授权的业务界面或停写维护方案 |
| 数据恢复 | 由负责人与业务管理员确认范围，先在隔离目录演练 |

## 接管检查

    systemctl is-active rm-progress
    sudo journalctl -u rm-progress -n 30 --no-pager
    curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:80/login

完成接管前阅读[服务器运维手册](服务器运维手册.md)、[发布检查与数据恢复](发布检查与数据恢复.md)并核对 SSH 密钥撤销流程。
