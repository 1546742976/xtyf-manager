# 一键排期本地验收（2026-10-16）

本次源码实现依赖优先排期，规则及接口见 [任务排期](../usage/任务排期.md)。所有测试使用隔离临时数据库和本机回环地址，未修改生产数据库、部署服务器或推送 GitHub。

## 已实现范围

- 合并主前置和其他前置，按依赖顺序计算；全部前置允许提前两个日历日衔接，不早于前置开始日。
- 默认只顺延并保留工期；缺少有效区间时在预览补工期。进行中和持久固定日期默认受保护，可明确允许本次调整。
- 跨车组前置只读，检查固定约束冲突；实际完成日期优先，回退计划截止日时提示。循环和失效依赖阻止整批保存，同负责人重叠只提醒。
- v2 签名预览、外部前置快照、原子保存及逐项修订撤销；旧协议需刷新页面。
- 输入使旧预览失效，迟到响应不能覆盖新方案；网络失败和 HTTP 409 保留输入，首次网络失败可直接重试；保存期间阻止关闭、替换和重复提交。
- 迁移 v8 增加 `schedule_locked`，默认关闭，不从历史日期来源推断固定。创建、编辑、权限、修订及撤销均支持此字段。

本地证据位于忽略目录：`.build-tools/schedule-python-tests.log`、`.build-tools/schedule-js-tests.log`、`.build-tools/schedule-browser-check/result.json` 及同目录截图。本记录覆盖本次排期改动，不替代其他并行开发内容的验收。
