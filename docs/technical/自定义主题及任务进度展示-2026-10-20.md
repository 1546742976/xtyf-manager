# Logo、任务进度附图与自定义主题

- 使用仓库内 `clients/assets/xtyf-logo.svg` 的同一透明矢量图作为所有主题和登录界面的 Logo；静态资源直接复用原始 SVG，容器使用透明底色和一致的 12px 圆角。
- 任务中心卡片使用 `latest_progress.image_ids` 显示最近记录的最多两张附图，与工作台统一读取 `/api/task/<id>/attachments/<attachment_id>`；有图无文字仍显示附图，无备注无图时不渲染动态框。
- 账户设置新增自定义浅色、深色两套主题，主题色分别保存并跨设备同步，保留八套预设及跟随系统。
- SQLite 幂等迁移新增 `members.light_custom`、`dark_custom`、`light_accent`、`dark_accent`，原内建配色字段 CHECK 约束保持不变。
- API 对颜色进行严格 `#RRGGBB` 校验，兼容旧三字段预设选择与单字段切换；利用 color-mix 提高极端主题色对比度，首屏脚本在绘制前应用自定义色，不依赖 localStorage。
- 相关测试覆盖附图、纯图片记录、配色交互、颜色验证、账号同步和迁移。
