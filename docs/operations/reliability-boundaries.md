# 来源识别、进度连接与部署自检

## 可信代理（默认关闭）

`TRUSTED_PROXY_CIDRS` 默认为空，应用只使用连接对端 IP，忽略转发头。
该配置只改变登录限流、账号/IP 组合计数和失败审计节流的来源识别；不信任转发的 Host、协议，不改变 Cookie。

仅在确认真实代理拓扑后，由运维在服务环境中填写逗号分隔的代理 CIDR。
例如单机代理确实从回环 IPv4 连接时才可使用 `127.0.0.1/32`；不要照抄示例作为生产配置。
IPv6 使用原生 IPv6 CIDR；IPv4 映射地址归一化为 IPv4，应使用 IPv4 CIDR。
无效 CIDR、带主机位的网段、空条目、全网网段（包括组合后覆盖全网）阻止启动。

应用仅在直接对端可信时读取 `X-Forwarded-For`，全链校验后从右向左跳过可信代理，取首个非可信 IP。
最多 2048 字符、16 个地址；非法链、超限链或全部可信的链均保守使用连接对端。
代理必须追加或重建真实来源；应用端口必须限制直接访问，不能信任来自用户可控网段的任意机器。
启用前确认每层代理的来源、转发头规则、IPv4/IPv6 路由及防火墙。

真实 NAT 出口的不同成员仍共享 IP 限额。未核对生产拓扑前，不能宣称解决了线上连带限流。
关闭时清空配置并重启服务。回滚相关代码前先移除配置；原计数窗口自然到期，不删除业务数据。

## 发票进度

新版公共页面采用同一轮询实现：活动任务约 3 秒、空闲 15 秒；失败退避 5/10/20/30 秒。
隐藏、离线或离开页面暂停，恢复立即查询；鉴权失败停止。分页漏掉关注任务时查询任务详情。
结果查询不会重新提交后台任务。

旧 SSE 地址继续可用，每个进程最多 4 条、每位成员 1 条，超过立即返回 429、
`reason=sse_capacity`、`Retry-After: 5`。生成阶段最长 30 秒，心跳 5 秒。
额度不是跨进程限制；保留部署的 1 worker / 8 threads，不建议仅增加 worker 绕过线程占用。
WSGI 服务器感知客户端断开可能晚于浏览器关闭，释放时间还取决于输出和连接状态。
回滚此保护会恢复旧版线程耗尽风险。

## 旧部署入口

`deploy/deploy.sh` 的 `HEALTH_URL` 默认是 `http://127.0.0.1:80/login`。
可设置不含凭据的 HTTP/HTTPS 最终地址；不把重定向或其他非 200 状态当作成功。
健康判定同时要求服务 active 和 HTTP 200：最多 30 次，连接 2 秒、请求 3 秒，间隔 1 秒。
网络或 HTTP 失败耗尽会非零退出，不输出“部署完成”；服务可能已更新，需按日志人工处理。
没有自动删除数据或自动回滚。同步、安装及重启失败也保持非零退出。
撤销此修复会恢复旧健康检查误报成功的行为。
