# 巡天御风管理系统 · 成员使用手册

适用对象：全体队员（普通成员）
最后更新：2026-10-12

---

## 1. 系统简介

战队内部管理平台，包含三个模块：

| 模块 | 作用 | 谁能看 |
|---|---|---|
| **进度看板** | 查看全队任务和每人负责的事项 | 所有人 |
| **我的发票** | 上传报销发票、跟踪自己的发票进度 | 所有人（只能看到自己上传的） |
| **资金管理** | 战队资金台账 | 仅管理员/项管 |

## 3. 登录

1. 打开上面的地址，进入登录页
2. 输入账号密码：
   - **账号**：姓名拼音首字母小写。例如：
     - 陈虹宇 → `chy`
     - 周奕轩 → `zyx`
     - 王鹏宇 → `wpy`
   - **初始密码**：由管理员创建账号时指定或随机生成并单独通知
3. 登录后顶部导航进入「**账户**」→「修改登录密码」请务必修改初始密码（至少 8 位）

> 忘记账号或密码：联系管理员（陈虹宇）重置，重置后由管理员单独提供新密码。

## 4. 进度看板

登录后的首页就是**看板**，它每 5 秒自动刷新，不需要手动刷新。

### 4.1 界面说明

- **顶部统计**：总任务 / 进行中 / 已完成 / 阻塞 / 逾期
- **视图切换**：
  - 「**按人**」：每个人一列，显示他负责的任务
  - 「**按状态**」：按 未开始 / 进行中 / 已完成 / 阻塞 / 已取消 分组
- **筛选栏**：按组别、按状态筛选；搜索框可搜任务名/负责人/项目；勾选「**只看我的**」只看自己的任务

### 4.2 任务卡片怎么看

每张卡片显示：

- 任务标题 + **状态**徽章（灰=未开始、蓝=进行中、绿=已完成、红=阻塞、深灰=已取消）
- **优先级**徽章：🔴 高优先 / 🟠 中优先 / 🔵 低优先
- 项目、负责人、截止日期
- **剩余天数**徽章（系统每天按北京时间自动更新）：
  - 🔵 剩余 X 天（还有 4 天以上）
  - 🟠 剩余 X 天（3 天以内，注意了）
  - 🔴 已逾期 X 天
  - 「今天截止」/「未设截止」
- 逾期任务的卡片左侧有红色竖线标记

### 4.3 更新自己的任务

1. 点击自己负责的任务卡片，弹出任务详情
2. 可以修改：
   - **状态**（未开始 → 进行中 → 已完成；遇到问题改「阻塞」）
   - **本次更新备注**（写一句话说明做了什么，比如"完成云台转接件图纸"）
3. 点「保存更新」
4. 你的每次更新都会记录在任务下方的「更新历史」里，项管能看到

> 提示：状态和备注是每个人自己维护的，请保持及时更新，方便全队了解进度。

### 4.4 查看别人的任务

点任意任务卡片可以查看详情和更新历史（不能修改）。

### 4.5 协作任务（实现完成，待部署）

协作功能实现和浏览器流程验证已经完成，但还没有部署到生产环境。生产发布前，仍以当前线上页面为准。部署后适用以下规则：

- **组别和项目**：你可能同时属于多个专业组；任务可以关联多个组，但只会归入一个项目。筛选时可按组别或项目缩小范围。
- **负责人和参与者**：每个任务会显示一个总负责人和多个参与者。若你是负责人或参与者，可以更新除父任务外的任务设置和进度说明；只有管理员能维护任务的父子关系。
- **任务树与依赖**：任务树只表达父子层级。依赖关系单独显示，系统会提示前置任务未完成或建议的开始日期，但不会替你自动修改日期。
- **并发提示**：保存前若其他人已更新同一任务，系统会提示刷新后再处理，避免相互覆盖。详情中的修订记录用于追溯谁在何时改了哪些字段。
- **工作截图**：任务详情会提供截图留痕。一次最多选 5 张，每张最大 10 MiB，只接受 PNG、JPEG 或 WebP。截图仅供已登录用户在任务权限范围内查看，不会出现在公开网页地址中。

发现任务归属、依赖或附件权限不符合实际时，请先不要反复覆盖保存，记录任务名称和提示内容后联系项管。

## 5. 我的发票（上传报销发票）

### 5.1 入口

顶部导航栏点「**我的发票**」。

### 5.2 上传发票

1. 把 PDF 发票文件**拖拽**到页面中间的虚线上传区（或点击选择文件）
2. 支持一次拖入多个文件批量上传
3. 系统会自动识别：金额、开票日期、发票号码、供应商
4. 识别完成后自动入库，规则如下：
   - **提交人自动记为你本人**（不用填、也不会填错）
   - 状态固定为「**未报销**」（报销流转由财务操作）
   - 如果检测到可能重复的发票（同一发票号），会弹窗提醒并询问是否继续
5. 入库后可以在列表中看到这张发票

> 发票建议在拿到后尽快上传，避免丢失导致无法报销。

### 5.3 查看自己的发票

- 列表只显示**你上传的**发票（别人的你完全看不到）
- 每张发票显示：月份、日期、状态、类别、供应商、金额、发票号
- 点「**打开**」或供应商名：在浏览器里直接预览 PDF
- 点「**查看**」：看发票详情（备注等）
- 状态含义：
  - 未报销（红）：还没走报销流程
  - 正在报销（黄）：财务正在处理
  - 已报销（绿）：报销已经打款完成

### 5.4 统计

点顶部「**统计**」按钮，可以看你自己的发票数量、总金额和各状态分布。

## 6. 常见问题

**Q：登录提示"用户名或密码错误"？**
A：检查账号和密码。15 分钟内连续输错 6 次将被限制登录 15 分钟；忘记密码请联系管理员重置。

**Q：看板上的剩余天数怎么算的？**
A：按北京时间，截止日期减去今天；每天自动更新，不用管。

**Q：发票上传后看不到？**
A：确认上传成功了（有成功提示）；如果仍看不到，刷新页面重试。

**Q：为什么我看不到"资金管理"？**
A：资金管理只对管理员和项管开放，普通成员看不到入口，这是正常权限设置。

**Q：手机能访问吗？**
A：可以。校外用流量访问 `http://47.116.50.22:10030` 或 `http://manager.skywalker-rm.online` 即可。

**Q：页面样式显示异常？**
A：按 `Ctrl + F5`（手机长按刷新）强制刷新一次。
