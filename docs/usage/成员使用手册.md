# 成员使用手册

适用对象：所有已登录成员。说明对应仓库 `main` 当前代码；线上页面是否已经更新，请以部署版本为准。

## 进入工作台

使用管理员提供的实际访问地址与登录用户名、初始密码。新成员初始密码由管理员单独告知；新建或重置的账号首次登录会强制进入 **账户设置** 改密，设置与初始密码不同的新密码后才能进入工作台。忘记密码时联系管理员或项管重置，不要在群聊中发送密码。

左侧导航按权限显示：工作台、任务中心、协作、我的发票、账户设置；管理员和项管还可以看到任务管理、成员管理、资金台账等。

## 账户设置（`/account`）

- **外观**：在顶栏外观菜单或账户设置选择四套亮色／四套暗色主题，或跟随系统；亮暗配色分别记忆，点击后立即切换并保存到账户。其他设备下次打开或刷新页面时同步，不影响已登录会话。保存失败时恢复原主题，可点击重试；首次登录先完成改密。
- **可以修改**：自己的登录用户名、所处专业组（多选）、参与造车组别（多选），以及验证当前密码后修改密码（新密码至少 8 位）。
- **不能修改**：成员 ID、真实姓名、系统角色或自己的启停状态。需要修改姓名请联系管理员。
- `members.id` 是系统内部稳定的数字身份标识，**不是登录用户名**；更换用户名不会产生新账号、也不会改变任务归属。旧用户名在修改后不再能登录。

## 专业组和造车组别

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 专业组 | 人员技能与分工，可多选 | 视觉、电控、机械、硬件、宣传、运营 |
| 造车组别 | 参与的机器人/车种项目，可多选 | 步兵、哨兵、重装、飞镖及自定义 |

**任务只归属一个造车组别**。例如同一位视觉成员可以同时参与步兵和哨兵任务，任务不会被自动归到“视觉”。

## 工作台和任务中心（`/`、`/tasks`）

按人视图不显示管理员任务栏。未分配任务位于筛选栏下方最上方，卡片横向排列，遵循当前筛选；没有匹配的未分配任务时整块隐藏。账户设置中的「外观」位于「个人信息」下方。
专业组视图使用时间轴，每个任务独立一行，显示负责人、状态及起止日期；同日任务用标记展示，缺失或非法日期显示文字说明。筛选保留当前车组的时间坐标。手机上显示纵向阶段列表；点击任务或用键盘打开详情。
选择单一造车组别后，任务中心默认按负责人专业组展示「机械 → 电控 → 视觉」，也可切换其他视图；未归类任务单独展示。专业组不决定排期先后，一键排期按具体前置约束、默认只顺延并保留原工期。可在任务编辑中勾选“自动排期时固定日期”；实际应用后可在日期和版本记录查看结果。操作规则见 [任务排期](任务排期.md)。

- 查看任务概况，切换 **按人 / 按状态 / 任务树**。
- 可以按造车组别、状态筛选，也可搜索任务、切换“只看我的”、手动刷新和导出任务 CSV。
- 点击任务查看标题、总负责人、参与者、状态、优先级、日期、说明、更新历史、依赖与截图等。
- **总负责人和参与者**可以编辑本人负责／参与任务的一般设置、进度及主前置任务和其他前置依赖；管理员与项管可编辑所有任务。其他成员可查看，但不能借 API 越权修改。撤销任务修订仍仅限管理员。
- **主前置任务**兼容原父任务关系；其他前置任务表示额外依赖。新建时根据主前置结束前 2 天预填开始日期，且不早于其开始日，手动修改后不再替换。保存后的日期不自动跟随；可点击“重置为依赖时间”重新取一次建议。所有前置的日期提醒都遵守相同的两天衔接规则。
- 保存前如别人已更新该任务，可能提示版本冲突；刷新详情、确认新版本后再改，勿用旧表单覆盖。
- 截图留痕：支持 PNG/JPEG/WebP，单次最多 5 张、每张不超过 10 MiB；文件需要登录并经权限检查，上传者或管理角色可以删除。
- 任务删除是**逻辑删除**，不等同于成员或组别的可恢复归档：当前没有任务恢复的用户入口。

## 我的发票（`/invoices/`）

1. 上传 PDF 发票，检查系统读取到的发票信息和重复提示。
2. 按页面流程确认暂存文件入库；非管理角色的提交人按当前成员身份记录，不能代替别人提交或自行切换报销状态。
3. 在列表中查看本人发票、状态、金额和文件预览；如归属不正确，联系财务负责人处理。
4. “未报销 / 正在报销 / 已报销”的业务流转由有财务管理权限的人维护。识别结果可能不准确，以票据原件及人工复核为准。

发票列表与预览在服务端按成员 ID 校验归属；历史无法明确归属的票据由财务人工确认，姓名不作为访问权限证据。

上传确认时修改的日期、供应商及金额会保留为确认值；空日期或供应商表示未知。批量确认失败的条目保留暂存文件，可修改后重试。重复提示只展示类型，不会公开其他成员的文件路径。

## 协作（`/discussions`）

全员可以发起话题、回复和上传任意格式文件。标题最多 120 字，正文最多 5000 字；每条最多 5 个文件、单个 100 MiB、总计 180 MiB。图片提供安全缩略图，其他文件下载查看。

消息不可编辑；作者可在不足 120 秒内撤回，整话题还要求无回复。管理员、项管可随时撤回。撤回后显示占位，原件在服务器长期保留，站内停止提供。切换话题保留本页草稿；发送失败保留文字及文件，超时会先核对结果，手动重试不重复发帖。未读按账户同步，阅读旧消息不强制跳到底部。

详见[本地协作使用及存储说明](../technical/本地协作.md)。此功能不连接 GitHub，不改变 22:00 项目晚报。

## 常见问题

- 登录失败：核对用户名与密码。短时间多次失败会触发限流；由管理员执行密码重置。
- 找不到管理按钮：这通常是角色权限限制，不是页面故障。
- 任务或组别没有显示：检查筛选条件；已删除/归档记录可能只允许管理员查看。
- 页面内容与本文不同：可能尚未部署最新 `main`；请先核对服务器实际版本，不要直接用文档推断生产能力。

## 任务中心与首页目标

任务中心顶部可切换“造车任务”和“日常项目”。日常项目继续按机械、电控、视觉分别更新，不拆为造车子任务，历史备注、图片和负责人保留。旧项目链接和邮件链接仍可打开。

管理员和项管在两个标签页均使用“新建任务”按钮，弹窗内选择造车任务或日常项目，默认当前标签页类型。切换类型、关闭后再打开以及保存失败时，当前页面内未提交的内容保留；刷新页面不会保留草稿。编辑已有日常项目时类型固定。分组负责人可按姓名或专业搜索，多选状态会显示已选人数，管理员不作为负责人候选。

首页配置目标后显示剩余天数；当天显示“今天”，过期显示“日期已过”。日期按北京时间计算，只有管理员可以配置。侧栏外观按钮切换到记忆的另一种亮暗配色，并退出跟随系统。
