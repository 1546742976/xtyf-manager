# 管理员与项管操作手册

本文依据仓库 `main` 现行实现，主要面向 `admin`（管理员）和 `manager`（项管）。**管理入口是否可用取决于生产部署的实际代码版本**。

## 角色和操作边界

| 操作 | 普通成员 | 项管 | 管理员 |
| --- | --- | --- | --- |
| 浏览任务、导出任务 CSV | 是 | 是 | 是 |
| 编辑自己负责/参与的任务 | 是 | 是 | 是 |
| 创建、管理、逻辑删除任务 | 否 | 是 | 是 |
| 维护主前置任务及其他前置依赖 | 仅本人负责／参与的任务 | 是 | 是 |
| 撤销任务修订 | 否 | 否 | 是 |
| 查看成员管理、添加成员、批量导入 | 否 | 是 | 是 |
| 修改任意成员完整资料、角色与软删除/恢复 | 否 | 否 | 是 |
| 编辑组别字典名称、新增条目 | 否 | 是 | 是 |
| 删除 / 恢复专业组或造车组别 | 否 | 否 | 是 |
| 资金台账 | 否 | 是 | 是 |
| 管理全部发票 | 需独立授权 | 需独立授权 | 需独立授权 |
| 配置财务权限 / 查看审计 | 否 | 否 | 是 |

管理员在 **权限与审计**（`/admin/security`）按成员 ID 授予资金审核和发票管理权限。资金审核人同时需要管理员/项管角色；`FUNDS_REVIEWERS` 只用于首次迁移旧授权。

## 成员管理（`/members`）

### 新增、导入和查找

- 新建成员：填写姓名、专业组（多选）、造车组别（多选）、登录用户名和初始密码；密码留空会随机生成，只在本次结果中显示，应逐人通过可信渠道私下交付，遗失后重新重置。新建、导入、重置账号首次进入时必须改密，不能沿用初始密码直接操作业务。
- 批量导入：每行 `姓名,专业组1;专业组2[,用户名]`，多个专业组用**分号**隔开、CSV 列用**逗号**隔开；整个批次可以统一选择若干造车组别。每位成员获得不同的初始随机密码。
- 列表按姓名/用户名、专业组、造车组别和角色筛选；“导出成员 CSV”在页面上方。

### 管理资料和账户

- **仅管理员**可通过“编辑资料”统一修改任意成员的姓名、用户名、两类组别、权限角色、启停状态和其他成员密码。
- 成员本人可以在“账户设置”修改用户名和两个组别；**姓名由管理员统一管理**。成员 ID 不可修改，登录用户名可以变更。
- 管理员不能更改自己的权限角色、停用/删除自己，不能绕过验证原密码通过管理接口重置自己的密码。
- 项管可以使用已有快捷操作管理普通成员的组别、密码和启停，但不能调用管理员完整资料 API。

### 删除、恢复与字典

- **删除成员**：管理员输入目标登录用户名确认；系统设置 `deleted_at`、停用账号并使已有会话失效，不物理删除历史业务关联。
- **恢复成员**：勾选“显示已删除成员”→“恢复账号”；恢复后**仍处停用状态**，需管理员再明确启用。
- **专业组 / 造车组别**：在页面字典或任务管理页增改名称。仅管理员可执行“删除/恢复”，确认时输入完整组名；删除是软删除，禁止新分配但历史成员、任务和修订引用仍保留。
- 已删除组别名称不能直接同名新建，应恢复原目录项。专业组默认预置视觉、电控、机械、硬件、宣传、运营；造车组别默认预置步兵、哨兵、重装、飞镖。初始化预置仅执行一次，之后的重命名不会被重置。
- 切勿把专业组当作任务的归属组。**成员两种组别都可多选，任务只关联一个造车组别。**

## 任务管理（`/manage`）

任务中心的阻塞任务以完整红框和「阻塞」文字提示；黑色主题下任务卡片和发票页的统计、导出、查重按钮使用暗色背景。成员添加表单先填姓名与用户名、密码与角色，再选两种组别；批量导入在独立区块操作。
任务中心的专业组视图采用时间轴，任务管理保留操作表格。银白／黑色主题在「账户设置 → 外观」选择，保存到账户并在其他设备下次打开或刷新时同步；不会改变任务日期或权限。
任务列表选择单一造车组别后，点击「一键排期」可预览整组任务，不受搜索和状态筛选影响。排期按主前置与其他前置约束，允许提前最多两天衔接，默认只顺延并保留工期；专业组仅用于展示。进行中及明确固定的任务默认受保护，可允许本次调整；缺日期可在预览内补工期。预览后数据变化会阻止整批保存，需重新核对。完整流程见 [任务排期](任务排期.md)。

1. 创建任务：标题、总负责人、一个造车组别、多个参与者、状态/优先级/起止日期、说明和前置依赖；有参与者时必须有负责人。
2. 主前置任务兼容原“父任务”关系；管理员、项管可编辑所有任务的主前置和其他前置依赖，普通成员仅可编辑本人负责／参与的任务。系统联合检查两种关系，阻止依赖环；修改依赖不会自动覆盖已保存日期。
3. 管理员/项管可编辑任务，负责人或参与者也可更新其参与任务的普通字段。多用户更新采用 `version` 乐观并发检查。
4. “修订历史”记录字段前后值；管理员可撤销，但后来已修改过的字段不能强行撤销覆盖。
5. “删除任务”为逻辑删除，存在未删除子任务或仍被其他任务依赖时将拒绝。**目前没有任务恢复界面/API**，与成员/组别的可恢复删除不同。
6. 任务与成员 CSV 均可导出。任务 CSV 中“组别”表示造车组别，旧“项目”列属于兼容字段。

## 资金台账（`/funds/`）

管理员和项管可管理收支记录、统计与导出。审核操作只允许“权限与审计”中明确授权的合资格账户；已审核记录内容变化后回到“待审核”，须重新审批。不要把审批按钮是否可见视为唯一授权依据。

审核绑定当前页面读取的记录版本。出现“记录已变更”时，本次审核未通过；刷新后重新核对金额和其他字段，再决定是否审核。旧页面升级后须刷新，不会自动重试过期审核。

## 发票中心（`/invoices/`）

取得“发票管理”权限的成员可处理全部发票、批量维护报销状态、查重与归档、下载 CSV/ZIP；未授权账号只能提交和查看自己的发票。提交人使用带成员 ID 的选项，同名成员可区分；改名后仍归原 ID。历史同名或无法匹配的记录在“归属待确认”筛选下由财务人工选择成员确认。提交人、状态及原文件需人工核对，不应把 PDF 自动识别当作财务核验。

上传确认表中的日期、供应商和金额会成为确认值；明确清空日期或供应商表示未知，后续 PDF 解析不会覆盖它们。批量确认中非法条目保留临时文件，可修改后重试；有效条目可正常入库。整理多层目录时保留已有归属、确认值和报销状态。

新增任务、成员和批量导入中的选择会在自动刷新时保留；若选择的成员被停用或组别、依赖被删除，页面显示提示并阻止提交，需重新选择或取消失效项。

## 八套主题、目标日期与统一任务中心（2026-10-16）

- 顶栏“外观”或账户设置可选择银白蓝、RM 机甲红蓝、云雾绿、奶霜猫爪粉，以及深空蓝、暗色 RM、石墨灰金、雪梨星语。每人只修改自己的偏好，支持跟随系统。
- 管理员在首页点击“设置目标日期”，填写统一目标和日期；同时清空两项可隐藏。项管和成员仅查看。发生版本冲突时，先核对并加载最新设置，再重新编辑。
- 任务中心两个标签页共用“新建任务”入口和弹窗，弹窗内可选择造车任务或日常项目，默认当前标签页类型。手机显示全屏表单，说明、人员、日期和依赖分区排列；切换类型、关闭后再打开和保存失败时保留当前页面内的草稿，刷新页面后不保留。提交中禁止重复保存。
- 新建开始日期默认参考主前置结束前 2 天，且不早于前置开始日；保存后不自动跟随依赖。可单独勾选“自动排期时固定日期”；一键排期默认保护固定与进行中任务，明确允许本次调整后才可覆盖。
- “日常项目”收进任务中心标签页，项目 ID、各组版本、负责人、图片和历史保留，邮件提醒计算不变。
- 日常项目按机械、电控、视觉分组选择负责人，支持姓名／专业搜索与多人勾选；管理员不进入候选。历史项目含管理员或不可分配的负责人时，编辑窗口会提示重新确认有效负责人。编辑已有项目使用同一弹窗，类型固定为日常项目。


## 本地协作模块

协作内容保存在主库及 `TASK_ATTACHMENTS_DIR/collaboration`，撤回原件长期保留。完整快照和恢复必须包含两者；日常分时备份不含附件，不能代替完整恢复点。服务模板上传等待已调整到 240 秒，代理需允许至少 200 MiB。部署前核对实际路径和代理配置，详见[本地协作](../technical/本地协作.md)。
