# 管理员与项管操作手册

本文依据仓库 `main` 现行实现，主要面向 `admin`（管理员）和 `manager`（项管）。**管理入口是否可用取决于生产部署的实际代码版本**。

## 角色和操作边界

| 操作 | 普通成员 | 项管 | 管理员 |
| --- | --- | --- | --- |
| 浏览任务、导出任务 CSV | 是 | 是 | 是 |
| 编辑自己负责/参与的任务 | 是 | 是 | 是 |
| 创建、管理、逻辑删除任务 | 否 | 是 | 是 |
| 维护父任务关系 / 撤销任务修订 | 否 | 否 | 是 |
| 查看成员管理、添加成员、批量导入 | 否 | 是 | 是 |
| 修改任意成员完整资料、角色与软删除/恢复 | 否 | 否 | 是 |
| 编辑组别字典名称、新增条目 | 否 | 是 | 是 |
| 删除 / 恢复专业组或造车组别 | 否 | 否 | 是 |
| 资金台账、管理全部发票 | 否 | 是 | 是 |

资金审批另受 `FUNDS_REVIEWERS` 限制：**被列入且同时具有管理员/项管角色**的人才有审核权限；并非所有管理员默认可审核。

## 成员管理（`/members`）

### 新增、导入和查找

- 新建成员：填写姓名、专业组（多选）、造车组别（多选）、登录用户名和初始密码；密码留空会随机生成，显示后应一次性安全传达。
- 批量导入：每行 `姓名,专业组1;专业组2[,用户名]`，多个专业组用**分号**隔开、CSV 列用**逗号**隔开；整个批次可以统一选择若干造车组别。每位成员获得不同的初始随机密码。
- 列表按姓名/用户名、专业组、造车组别和角色筛选；“导出成员 CSV”在页面上方。

### 管理资料和账户

- **仅管理员**可通过“编辑资料”统一修改任意成员的姓名、用户名、两类组别、权限角色、启停状态和其他成员密码。
- 成员本人可以在“账户设置”修改用户名和两个组别；**姓名由管理员统一管理**。成员 ID 不可修改，登录用户名可以变更。
- 管理员不能更改自己的权限角色、停用/删除自己，不能绕过验证原密码通过管理接口重置自己的密码。
- 项管可以使用已有快捷操作管理普通成员的组别、密码和启停，但不能调用管理员完整资料 API。

### 删除、恢复与字典

- **删除成员**：管理员输入目标登录用户名确认；系统设置 `deleted_at`、停用账号并使已有会话失效，不物理删除历史业务关联。
- **恢复成员**：勾选“显示已删除成员”→“恢复账号”；恢复后**仍处停用状态**，需管理员再明确启用。
- **专业组 / 造车组别**：在页面字典或任务管理页增改名称。仅管理员可执行“删除/恢复”，确认时输入完整组名；删除是软删除，禁止新分配但历史成员、任务和修订引用仍保留。
- 已删除组别名称不能直接同名新建，应恢复原目录项。专业组默认预置视觉、电控、机械、硬件、宣传、运营；造车组别默认预置步兵、哨兵、重装、飞镖。初始化预置仅执行一次，之后的重命名不会被重置。
- 切勿把专业组当作任务的归属组。**成员两种组别都可多选，任务只关联一个造车组别。**

## 任务管理（`/manage`）

1. 创建任务：标题、总负责人、一个造车组别、多个参与者、状态/优先级/起止日期、说明和前置依赖；有参与者时必须有负责人。
2. 任务树“父任务”仅管理员可设置；前置依赖和父子层级会分别防环。依赖提示不会改写日期。
3. 管理员/项管可编辑任务，负责人或参与者也可更新其参与任务的普通字段。多用户更新采用 `version` 乐观并发检查。
4. “修订历史”记录字段前后值；管理员可撤销，但后来已修改过的字段不能强行撤销覆盖。
5. “删除任务”为逻辑删除，存在未删除子任务或仍被其他任务依赖时将拒绝。**目前没有任务恢复界面/API**，与成员/组别的可恢复删除不同。
6. 任务与成员 CSV 均可导出。任务 CSV 中“组别”表示造车组别，旧“项目”列属于兼容字段。

## 资金台账（`/funds/`）

管理员和项管可管理收支记录、统计与导出。审核操作只允许 `FUNDS_REVIEWERS` 配置的合资格账户；已审核记录内容变化后回到“待审核”，须重新审批。不要把审批按钮是否可见视为唯一授权依据。

## 发票中心（`/invoices/`）

管理员和项管可处理全部发票、批量维护报销状态、查重与归档、下载 CSV/ZIP；普通成员只能提交和查看自己的发票。提交人、发票状态及原文件需人工核对，不应把 PDF 自动识别当作财务核验。部分历史票据存在姓名匹配兼容行为，请在改名或同名场景中谨慎检查。

## 变更前后

所有涉及删除、迁移或更新服务的操作，必须参阅 [发布检查与数据恢复](../technical/发布检查与数据恢复.md)；不可只依赖当前定时数据库备份脚本。运行环境/审核人配置参阅 [配置与权限参考](../technical/配置与权限参考.md)。
