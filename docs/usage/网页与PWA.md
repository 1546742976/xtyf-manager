# 网页与 PWA 使用说明

推荐在浏览器打开 **https://manager.skywalker-rm.online/**。服务端部署本次代码后，支持的浏览器可将同一个网站安装到桌面或主屏幕；安装不会建立另一套业务界面。Windows、Linux、Android 旧客户端继续作为兼容方案保留，本次不生成或发布安装包。

## 安装、更新与卸载

- Windows Chrome / Edge：打开网站，使用地址栏的安装图标或浏览器菜单的“安装应用”。账户设置的“安装到设备”也会在浏览器允许时提供按钮。安装后可从开始菜单打开独立窗口。
- Android Chrome / Edge：浏览器菜单 → 安装应用 / 添加到主屏幕。具体文字和是否提供独立窗口取决于浏览器与系统版本。
- iPhone / iPad Safari：分享 → 添加到主屏幕。这里没有 Chromium 的安装按钮事件；相机、下载、打印与后台行为可能不同，需要实际设备验收。
- 没有安装入口时，直接在浏览器使用相同功能；不要为了安装绕过证书警告。普通局域网 HTTP 地址通常无法使用 Service Worker 或摄像头；开发时可用受信任的 HTTPS 或本机 `http://127.0.0.1:8520`。

网站的业务页面与脚本每次通过网络获取。公共安装资源出现新版本时，账户页提示“更新已准备好”；保存工作后关闭所有本站标签页和应用窗口，再重新打开。不自动刷新，不打断草稿。操作系统显示的图标、应用名称更新可能延迟。

卸载可使用独立窗口的应用菜单，或系统/浏览器的应用管理入口。卸载应用不等于删除服务端账户及业务资料；浏览器若同时清除站点数据，会影响本机登录状态。

## 登录、主题与离线

- 使用网站原有账户和 Cookie 会话。是否共享登录取决于同一浏览器的配置文件/存储环境；不同浏览器、无痕模式、iOS 主屏幕环境可能需要分别登录。关闭重开在 Cookie 有效且未被清理时保持会话，服务端有效期目前为 30 天；退出、改密、停用、服务端策略或清除站点数据均可能使其失效，不保证永久登录。
- 主题以账户设置为准。同一账号在其他窗口或设备刷新/重新打开后读取新设置。系统模式随各设备的亮暗设置变化，因此不同设备外观可以不同；自定义配色继续使用原有账户接口。
- 仅缓存公共安装资源和无个人数据的离线说明。离线新开业务页面显示“当前离线，业务操作需联网”（缓存已清理时可能是浏览器离线错误），不会提供旧库存、任务或财务数据。页面打开后断网会显示提示；已显示的数据可能过时，未提交内容不自动上传。
- 提交中断网时，请恢复连接后先核对记录，再决定是否重试；没有离线写入队列或后台自动补提交。

## 扫码、上传、下载与打印

相机仅在使用扫码时申请权限；拒绝后仍可粘贴标签或选择已有图片。真实设备连续扫码至少 5 分钟、切换应用释放摄像头等项目须按[技术验收清单](../technical/PWA迁移与运维.md)验证。

图片和附件通过原有在线接口上传；PDF 标签在原有预览中生成并下载。若独立窗口没有合适的文件保存/打印入口，请在系统浏览器打开同一页面并登录后重试，使用下载的 PDF 按实际尺寸打印。打印机、保存对话框、iOS 文件处理存在平台差异，不能把未弹出对话框当成操作成功，也不要因此重复提交业务表单。

## 故障排查

1. 确认访问上述 HTTPS 地址、证书受信、网络可用，并在浏览器直接打开同一地址。
2. 安装按钮未出现时查看浏览器菜单；已安装、浏览器策略、访问频率和平台限制都会影响提示，不代表业务不可用。
3. 页面更新异常时先保存工作，关闭所有本站窗口再打开。仍失败可由管理员按运维文档撤回 Service Worker。
4. 需要清除站点数据时先保存草稿：浏览器设置 → 网站权限/站点数据 → 当前域名。此操作可能退出登录；正常升级无需这样做。
