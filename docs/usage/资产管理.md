# 资产管理

资产管理与现有平台共用账户及后端业务数据库。浏览器和客户端读取同一份库存；本地页面不保存离线库存，也不会离线排队提交借还。

## 首次配置

管理员或项管进入「资产管理 → 校区管理」创建实际校区，通过「类别管理」配置类别，再新增物品。不同型号或规格分别建条目，例如 M3×8 与 M3×12 螺丝。数量为整数，单位由管理人员填写。

- **可借用品**：例如电机。总量 = 在库 + 借出未还，借出不减少资产总量。
- **耗材**：例如螺丝。领用后减少剩余库存，累计领用单独展示，不与剩余库存相加。
- 列表合并各校区同一物品数量；切换校区后立即刷新并只汇总该校区，无需再次点击筛选。不同单位不汇总为一个数字。
- 点击物品名称进入独立详情页，查看分校区库存、当前借单与历史记录。记录可按校区筛选，调拨在两个涉及校区都能查到。

管理员可在「权限与审计」授予指定成员「资产管理」权限。项目管理者默认具备资产管理能力。

## 借用、领用与归还

所有登录成员点击卡片或登记按钮打开弹窗，选择校区、数量和北京时间，填写必填的用途／备注后登记自己的借用或领用；归还同样必填备注。流程不需要审批，必须在实际交接时如实登记。系统不允许代其他成员借用。

「我的借用」只显示自己的未还借单。归还关联原借单，可分批归还，回到原校区；不能超过未还数量。跨校区归还先登记原校区归还，再由资产管理员登记实际校区调拨。

网络失败时表单保留；原内容重试会复用同一个请求标识，避免重复扣库。若提示结果尚未确认，不要换一个窗口重复登记，应先重试原请求或刷新核对流水。保存未成功前，不以页面输入为库存凭证。

## 管理操作与纠错

- 入库：新增收到的在库数量，必填原因。
- 盘点：填写实际在库数量，不包含借出数量。库存被其他操作改变后，必须刷新重新核对。
- 调拨：从一个校区在库移至另一个启用校区，原子完成，总量不变。
- 纠错：对指定数量流水追加反向记录，必填原因，不删除原记录。同一记录只能纠正一次；若已有后续使用，撤回会导致数量不成立，则拒绝并要求核对后续流水。
- 启停：有在库数量或未还借单的物品、校区不能停用。历史记录保留；已有数量流水后，不直接变更物品计量单位或借还类型。

所有登录成员可查看库存和流水，并登记入库或调整在库数量（原因必填）；管理员、项管及获授资产管理权限的成员能维护目录、调拨及纠错。类别及物品通过停用移出使用目录，保留历史；类别下有启用物品时须先重新分类或停用物品。流水保存实际操作者和相关成员的姓名快照，时间采用北京时间。

## 客户端与交付

新版页面资源包含资产列表及详情路由。旧服务器的 bootstrap 未声明资产能力时，本地页面隐藏入口，直接访问则提示服务器尚未启用；其他业务不受影响。

源码和本地测试完成不代表线上已启用。资产模块需要正式部署配套后端与页面资源；本次不部署、不发布安装包、不递增版本。
