## 1. 系统架构

```
队员浏览器
 ├─ 实验室局域网 ──────────────► http://192.168.2.16
 └─ 校外 ──► 阿里云服务器 47.116.50.22
              ├─ TCP 10030（直连入口）
              ├─ TCP 10031（域名转发目标）
              └─ 域名 manager.skywalker-rm.online（nginx 转发 → 10031）
                        │
                        ▼ (frp 隧道 7000 端口)
                树莓派 5（实验室）
                 └─ gunicorn (端口 80) → Flask 应用 → SQLite
```

- **应用**：Flask + SQLite，单进程 gunicorn（1 worker / 8 线程，保证发票实时进度条正常）
- **隧道**：树莓派 frpc 主动连出到云服务器 frps（出站连接，树莓派无需公网 IP、无需端口映射）
- **云服务器**：由服务器管理员维护（DNS 解析、nginx 转发、安全组放行 7000/10030/10031）

## 3. 目录与服务

### 3.1 关键目录

| 路径 | 内容 |
|---|---|
| `/opt/rm-progress/` | 实际运行的代码 |
| `/opt/rm-progress/data.db` | 进度数据库（成员/任务/日志） |
| `/opt/rm-progress/data/funds/funds.db` | 资金数据库 |
| `/opt/rm-progress/data/funds/资金管理记录.txt` | 资金台账（自动同步） |
| `/opt/rm-progress/data/invoices/` | 发票数据（`月份/状态/` 文件夹 + `.invoice_meta.json` + `.invoice_cache.json`） |
| `/opt/rm-progress/backups/` | 自动备份 |
| `/opt/rm-progress/deploy/` | 部署脚本、systemd 服务模板、frpc 配置 |
| `/opt/frp/frpc.toml` | frp 客户端配置 |
| `/home/xtyf/progress_system/` | 代码"源目录"（部署脚本从这里同步到 /opt） |

### 3.2 systemd 服务

| 服务 | 作用 | 常用命令 |
|---|---|---|
| `rm-progress` | Web 应用（端口 80） | `sudo systemctl restart rm-progress`<br>`sudo systemctl status rm-progress`<br>`sudo journalctl -u rm-progress -f`（实时日志） |
| `frpc` | 校外访问隧道 | `sudo systemctl restart frpc`<br>`sudo journalctl -u frpc -n 50 --no-pager` |

两个服务都已配置**开机自启**和**崩溃自动重启**。

### 3.3 自动备份（cron）

- 每天 **3:17** 执行 `/opt/rm-progress/deploy/backup.sh`：
  - 进度库 → `backups/data-日期.db`（保留 14 天）
  - 资金库 → `backups/funds-日期.db`（保留 14 天）
  - 每周日：发票数据打包 → `backups/invoices-日期.tar.gz`（保留 60 天）
- 查看备份：`ls -lh /opt/rm-progress/backups/`

## 4. 更新部署流程

### 4.1 常规更新（推荐）

在陈虹宇电脑上修改本地代码 `D:\Robotmaster\管理\progress_system\`，然后：

```powershell
# 1. 上传修改的文件（按实际改动选择，示例上传单个文件）
scp -i "$env:USERPROFILE\.ssh\rm_progress" "D:\Robotmaster\管理\progress_system\app.py" xtyf@192.168.2.16:/home/xtyf/progress_system/app.py

# 2. 在服务器上执行部署
ssh -i "$env:USERPROFILE\.ssh\rm_progress" xtyf@192.168.2.16 "cd ~/progress_system && bash deploy/deploy.sh"
```

### 4.2 deploy.sh 做了什么

1. `apt-get install`：python3-venv / pip / sqlite3 / rsync / fonts-noto-cjk（中文图表字体）
2. rsync 代码 `~/progress_system/` → `/opt/rm-progress/`（**保留 data、数据库、密钥、备份**，不会覆盖数据）
3. 更新 venv 依赖（清华 pip 镜像）
4. 重装 systemd 服务并 **restart**（服务重启约 3 秒）
5. 自检并输出 HTTP 状态码（应为 200）

> 注意：数据库结构变更（如新增字段）由应用启动时自动迁移，无需手动执行 SQL。

### 4.3 回滚

重新上传旧版代码文件后再次执行 deploy.sh 即可（数据不受影响）。

## 6. 校外访问（frp）链路

### 6.1 配置说明

树莓派上的 `/opt/frp/frpc.toml`：

```toml
serverAddr = "47.116.50.22"
serverPort = 7000
auth.method = "token"
auth.token = "（与服务器端一致，勿外传）"

[[proxies]]
name = "xtyf-progress-http"     # 本地80 → 远程10031（供域名转发）
type = "tcp"
localIP = "127.0.0.1"
localPort = 80
remotePort = 10031

[[proxies]]
name = "xtyf-progress-tcp"      # 本地80 → 远程10030（IP直连）
type = "tcp"
localIP = "127.0.0.1"
localPort = 80
remotePort = 10030
```

改动配置后：`sudo systemctl restart frpc`，看日志出现 `login to server success` + `start proxy success` 即为正常。

### 6.2 校外打不开的排查顺序

1. 局域网能不能打开 `http://192.168.2.16`？
   - 不能 → 先修树莓派/应用（见第 8 节）
2. 树莓派上 `sudo journalctl -u frpc -n 30 --no-pager` 看隧道状态
   - `login to server success` → 隧道没问题，查云服务器侧（安全组 7000/10030/10031、frps 是否运行）
3. 直接访问 `http://47.116.50.22:10030` 能不能打开？
   - 能 → 域名问题：查 DNS（manager.skywalker-rm.online → 47.116.50.22）和服务器 nginx 转发（→ 127.0.0.1:10031）
   - 不能 → 云服务器安全组/ frps 问题，联系服务器管理员

## 7. 硬件维护

- **保持供电**：树莓派不能断电使用；断电后会自动开机重启（约 2 分钟服务恢复）
- 风扇曲线（`/boot/firmware/config.txt`）：45°C 起转、75°C 满速；正常情况下温度 40~55°C
- 查看温度：`vcgencmd measure_temp`
- 如需更换 Wi-Fi 或 IP：路由器 DHCP 保留已绑定 MAC `2c:cf:67:e3:e9:f8` → `192.168.2.16`

## 8. 常见故障排查

| 现象 | 排查 |
|---|---|
| 网页打不开（局域网） | `ssh xtyf@192.168.2.16` → `systemctl status rm-progress`；`sudo journalctl -u rm-progress -n 50` 看报错；`sudo systemctl restart rm-progress` |
| 页面显示旧内容 | Ctrl+F5 强刷；若是模板改动未生效 → 重新执行 deploy.sh（会重启服务） |
| 校外打不开 | 见第 6.2 节流程 |
| 忘记成员密码 | 管理员登录 → 任务管理 → 成员管理 → 「重置密码」（恢复为 123456） |
| 发票图表中文乱码 | `sudo apt-get install -y fonts-noto-cjk` 后 `sudo systemctl restart rm-progress` |
| 磁盘空间不足 | `df -h` 检查；清理 `.uploads/_待清理`、旧备份；一般 51G 可用，压力很小 |
| 服务启动失败 | `journalctl -u rm-progress -n 100` 看 traceback；常见是代码语法错误，回滚代码后重启 |

## 9. 安全注意事项

1. **SSH 私钥**（`rm_progress`）：仅陈虹宇电脑持有，勿复制到公开位置；如泄露，在树莓派 `~/.ssh/authorized_keys` 删除对应公钥并重新生成
2. **frp token**：相当于隧道密码，出现在 `frpc.toml` 与服务器端，勿发群里
3. **管理员账号**：建议强密码；成员离队及时「停用」账号
4. **资金/发票数据**：仅管理员+项管可见，不要在公开渠道传播导出的 CSV/压缩包
5. 目前校外访问为 HTTP 明文（登录密码在网络传输中未加密），账号密码请勿与其他系统重复；如需 HTTPS 可后续配置
